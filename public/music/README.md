# 博客音乐目录

把音乐文件放到本目录即可收录，子文件夹也会扫描。支持 MP3、M4A、OGG、WAV、FLAC、AAC、OPUS 和 WEBM，具体格式的播放能力由浏览器决定，优先使用 MP3。

播放器直接使用文件名作为歌曲名称，支持中文、空格和特殊符号。子目录会显示为名称的一部分。

## 背景音乐

在本目录放一个名为 `background.mp3` 的文件，作为全站背景音乐。也可使用其他支持的扩展名，例如 `background.ogg`。同名的多种格式同时存在时，按上方格式顺序选择。没有指定背景音乐时，使用排序后的第一首歌曲。

背景音乐也会出现在首页播放列表中。播放列表按路径名称排序，文件名前加 `01`、`02` 可以控制顺序。

```text
public/music/
  background.mp3
  01 月下散步.mp3
  02 夜间来信.m4a
  钢琴/
    雨后的街道.ogg
```

## 更新与播放

首页播放器中的「播放列表」按钮可以展开曲目浮层，列表可滚动。选择歌曲后会开始播放并收起列表；点击外部、关闭按钮或按 Esc 也能收起。播放器右侧的月下时计使用访问者设备的本地时间；表盘底图可按 `docs/moon-clock-prompt.md` 的提示词生成后放入 `public/images/`。

本地添加文件后，刷新预览页即可重新扫描。GitHub Pages 会在提交文件后，通过 GitHub Actions 重新构建、更新播放列表。只复制文件到已生成的 `dist` 目录不会更新列表。

首次播放需要点击播放器或右下角背景音乐开关。开关状态和音量会记在当前浏览器中，浏览器限制自动播放时会提示再次点击。首页播放器和背景音乐共用一个音频输出，切换时会暂停另一方。

通过站内链接切换首页、文章、手记目录、归档和关于页时，音乐会连续播放，曲目、进度、音量和暂停状态都会保留。刷新页面、关闭标签页或离开本站会重新加载页面，不属于连续播放范围。

使用自己有权公开分享的音频。本目录中的文件会作为网站静态资源公开发布。
