# 月夜背景图生成提示词

建议 16:9、2560×1440 或更高分辨率。

## 提示词

深邃的钴蓝与午夜藏青色天空，一轮银白满月位于画面右上三分之一，月面纹理细腻，薄薄的青蓝色光晕，厚重而柔软的层叠积云掠过月亮下方，云缘被冷月光照亮，天空留有大片暗色负空间，幽静、神秘、略带忧郁的日式视觉小说背景美术，精致手绘动画场景质感，电影级光影，克制的青色辉光，细腻空气透视，轻微胶片颗粒，高对比但保留暗部层次。画面左半部分深暗干净，方便叠加银白色博客标题。无人、无建筑、无文字、无标志、无界面、无水印。横向构图，16:9。

## 避免内容

文字、游戏标题、角色、人物剪影、霓虹城市、紫粉色主调、赛博朋克、过量星星、夸张镜头光斑、纯黑无细节、过曝月面。

## 使用位置

生成的图片已接入 `src/assets/moonlit-sky.png`，由 `NightSky.astro` 用作全站固定背景。Astro 构建时会生成响应式 WebP 图片，手机端单独调整裁切位置，背景微光与雾气动效由 CSS 叠加。
