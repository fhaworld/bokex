# 手记与短笺

内容都在本地 Markdown 文件里维护；推送后由 GitHub Pages 重新构建。

## 首页精选

在 `src/content/blog/` 的文章开头加入 `featured: true`，即可进入首页的「精选」。不写或设为 `false` 就不收录。

```yaml
---
title: "想推荐的一篇手记"
description: "一句话介绍这篇文章"
pubDate: "2026-11-04"
tags: ["随笔", "生活"]
featured: true
---
```

首页「精选」和「最近」各显示最多 3 篇，均按文章发布日期从新到旧排列。没有精选时默认显示「最近」。全部文章仍可从手记页查看。现有的第一篇手记和 Markdown 语法示例已设为精选，可自行替换。

## 月下短笺

在 `src/content/notes/` 新建 `.md` 文件，例如 `2026-11-05.md`：

```markdown
---
title: "今晚的小发现"
pubDate: "2026-11-05"
---

在这里写一小段文字，也可以使用 **加粗**、链接和列表。
```

首页侧栏显示最新 2 张短笺，「翻阅全部短笺」进入完整列表。短笺适合几句话的随想，长文请放到手记中。

`first-note.md` 是带有 `example: true` 标识的示例。可以删除，也可以修改标题、日期和正文，并去掉 `example` 一行。

## 文章延伸阅读

- 上一篇：按发布日期排序，较早的相邻文章。
- 下一篇：按发布日期排序，较新的相邻文章。
- 相关文章：标签有交集的其他文章，最多 2 篇；共同标签多的优先，再按发布日期从新到旧排列。
- 相关文章会排除当前文章和相邻文章；没有匹配内容时不显示该区域。

这些功能不需要配置第三方服务。
